# Персональный дашборд

Одностраничное приложение на чистом JavaScript (ES6 Modules), демонстрирующее
ООП-архитектуру UI-виджетов и работу с внешними API.

## Возможности

- Динамическое добавление и удаление виджетов
- Независимое состояние каждого виджета
- Корректная очистка ресурсов (слушатели, запросы) при удалении
- Состояния загрузки/пустой/ошибка/успех для API-виджетов
- Отмена устаревших запросов через `AbortController`
- Данные API вставляются только через `textContent` (без `innerHTML`)

## Архитектура

- `js/UIComponent.js` — абстрактный базовый класс: `render()`, `destroy()`,
  `minimize()`, `close()`, управление подписками и `AbortController`.
- `js/ToDoWidget.js` — локальный виджет: список дел с инкапсулированным состоянием.
- `js/QuoteWidget.js` — локальный виджет: массив цитат, кнопка «Обновить».
- `js/WeatherWidget.js` — API-виджет: погода (Open-Meteo).
- `js/CurrencyWidget.js` — API-виджет: курсы валют ЦБ РФ.
- `js/Dashboard.js` — реестр виджетов, `addWidget(type)`, `removeWidget(id)`.
- `main.js` — точка входа, инициализация, обработчики панели инструментов.

## Источники данных

- **Open-Meteo** — https://open-meteo.com/ — погода. Без ключа, с CORS.
- **ЦБ РФ (зеркало)** — https://www.cbr-xml-daily.ru/daily_json.js — курсы валют. Без ключа, с CORS.

## Ограничения

- Публичные API могут вернуть `429` при частых запросах — виджет покажет `error`.
- Погода фиксирована на Москве; координаты можно передать при создании виджета.
- Курсы валют обновляются ЦБ РФ раз в сутки (по рабочим дням).
